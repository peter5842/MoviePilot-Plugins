# MoviePilot-Plugins

MoviePilot V3 自用插件。在 MoviePilot「设定 → 插件 → 插件仓库」里添加本仓库地址即可在插件市场看到。

| 插件 | 作用 |
|---|---|
| 媒体库无人观看清理 `UnwatchedCleanup` | 删除 Plex 中超过设定天数无人观看、且不在订阅中的电影（逐部）和剧集（整部）。新命中的条目先发通知预告，宽限期内仍无人观看才删除；有整理记录的文件走 MoviePilot 自己的删除（媒体库 + 源文件 + 下载器任务），其余文件直接删除并清掉硬链接到它们的 qB 任务。也可自动删除媒体库和所有下载器均无引用的下载残留，独立设置周期及预览。 |
| 刷流动态配额 `BrushWeight` | 按各站最新分享率给「站点刷流」的每站任务分配保种配额和同时下载数：分享率越低配额越多。通过刷流插件自己的任务接口改写，停用的任务和数据异常的站点保持原样。 |

两个插件默认都是「仅预览」，确认结果后再关闭预览开关。

## 孤立下载文件清理（UnwatchedCleanup 1.1.0）

此功能属于媒体库无人观看清理插件，由 MoviePilot 宿主定时调度，不需要 Unraid 脚本、系统 cron 或另一个插件。与 180 天观看规则分开判断：默认每天 05:00 扫描，文件静置至少 1 天，每次最多处理 10 个直接子目录或单文件；观看规则仍默认每天 06:30 执行。

在插件设置里启用「清理孤立下载文件」，填写媒体库目录及下载目录映射。例如：

```text
/download/qBittorrent/shualiu:/downloads/shualiu
/media/download:/media/download
```

每行冒号左边是 MoviePilot 内的目录，右边是下载器看到的同一目录；多个下载器别名用逗号分隔。路径必须正确对应挂载，下载目录不能与媒体库重叠。新安装默认关闭此功能且仅预览；关闭「孤立文件仅预览」和全局「仅预览」后才实际删除。

清理条件：

- 所有已配置下载器都能完整读取，任意状态的下载或做种任务都保护其引用路径。停用但无法核对的下载器也会阻止本轮清理。
- 配置的媒体库无文件引用；设备号和 inode 同时比较，媒体库文件软链接也会保护源文件。
- 整个候选目录静置满设定天数。旧的未完成下载碎片失去任务后可清理，近期变化的内容保留。
- 删除每项前重新读取下载器、媒体库及文件身份，文件变化、额外硬链接、软链接目录、挂载点和特殊文件均保留。

实际删除释放空间，无法从插件恢复。页面保留最近 300 项操作记录，展示最近 100 项；中断或部分失败保留待核对记录，下一轮重新扫描剩余内容。私有文件、备份及配置目录不应加入下载目录映射。

插件数据页显示两类清理各自的结果。MoviePilot 后台服务中的「孤立下载文件清理」可按当前配置立即运行；`POST /api/v1/plugin/UnwatchedCleanup/orphans/preview` 始终只读预览，`GET /api/v1/plugin/UnwatchedCleanup/orphans/status` 读取状态，两者均需要 API 认证。
