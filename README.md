# MoviePilot-Plugins

MoviePilot V3 自用插件。在 MoviePilot「设定 → 插件 → 插件仓库」里添加本仓库地址即可在插件市场看到。

| 插件 | 作用 |
|---|---|
| 媒体库无人观看清理 `UnwatchedCleanup` | 删除 Plex 中超过设定天数无人观看、且不在订阅中的电影（逐部）和剧集（整部）。新命中的条目先发通知预告，宽限期内仍无人观看才删除；有整理记录的文件走 MoviePilot 自己的删除（媒体库 + 源文件 + 下载器任务），其余文件直接删除并清掉硬链接到它们的 qB 任务。 |
| 刷流动态配额 `BrushWeight` | 按各站最新分享率给「站点刷流」的每站任务分配保种配额和同时下载数：分享率越低配额越多。通过刷流插件自己的任务接口改写，停用的任务和数据异常的站点保持原样。 |

两个插件默认都是「仅预览」，确认结果后再关闭预览开关。
